# public/py

This folder is generated by `website/scripts/build-wheel.sh`. Do not edit by hand.

- `tidyfault-*.whl` is the Python package built from `python/` (pure Python).
- `wheel.json` names that wheel; `src/runtime/pyodide.js` reads it at run time and
  installs the wheel into Pyodide with micropip.

Rebuild after any change under `python/`:

    bash website/scripts/build-wheel.sh
